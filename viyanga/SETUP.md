# DailyBite PHP + MySQL Setup

1. Start Apache and MySQL in XAMPP.
2. Open phpMyAdmin and import `database.sql` from this folder.
3. If needed, update DB credentials in `includes/config.php`.
4. Open the app at `http://localhost/viyanga/index.php`.

## Default Admin Login

- Username: `admin`
- Password: `admin123`
